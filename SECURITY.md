# Reporting concerns

For a safety defect, provenance question or potential misuse concern, open an
issue with a concise description and a minimal synthetic reproduction. Never
post recovery keys, credentials, ROM/firmware dumps, raw event logs, device/boot
identifiers or a whole diagnostic directory. If a report needs sensitive material,
first ask for a private reporting channel without attaching that material.

This is experimental research for explicitly authorized hardware. UEFI GPU writes,
firmware execution and reset can leave the device or desktop unusable; an unknown
failure must not trigger an automatic retry or Windows handoff. No general hardware
compatibility or sustained stability is claimed. See README for the measured scope
and unresolved display problem. These cautions do not modify the software license.
